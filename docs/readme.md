# Manual

Read the [repository layout](layout.md) before changing files. It maps the site,
notebook source, tooling, and documentation boundaries.

1. [Environment](environment.md): install the workspace and optional native
   tools.
2. [Deployment](deploy.md): reproduce the GitHub Pages build.
3. [Notebooks](notebooks.md): open, check, catalog, and export course notebooks.
4. [Site](site.md): generate the catalog and build or serve the static site.
5. [Architecture](architecture.md): the packages, catalog, export pipeline and
   site, and which module owns each.
