Quick start:
uv sync --all-packages

Open a notebook:
uv run --package <package> marimo edit <notebook.py>

Check a notebook:
uv run --package <package> marimo check <notebook.py>

Some notebooks need external data or credentials.
Examples:
- técnicas-de-teledetección/correccion-atmosferica-gaofen1/main.py
- fundamentos-de-riesgos-y-desastres/analisis_huaicos_ancash.py
